<step name="initial">When the app is opened or refreshed, only the **top slider** is active, with the teacher able to swipe left, choosing the 'student' option, or swipe right, chosing the 'class' option.

![initial state](img/1_initial.png)
</step>
<hr>
<step name="student"> If the teacher chooses the 'student' option in the 

**top slider**, then the **ID dropdown menu** will activate, and the teacher can select the ID of the student he is interested in retrieving his homework assessments.

![student](img/2a_slide_student.png)

For example, if the teacher swipes the **top slider** to the left, and then selects 148 from the **ID dropdown menu**, this is what the GUI should look like:

![student 158](img/3_student_148.png)

</step>
<hr>
<step name="class">If the teacher chooses the 'class' option in the 

**top slider**, then the second slider will activate.

![class](img/2b_slide_class.png)

</step>
<hr>
<step name="pair">If the teacher swipes the second slider left, then the 

**'class code' dropdown menu** will activate, and the teacher can select which class he is interested in retrieving summed scores for each student in that class.

![cohort](img/4a_slide_pair.png)

For example, if the teacher selects the 'pair' option, and chooses class GCP-20, this is what the GUI should look like:

![class GCP-20](img/5_select_class_gcp-20.png)
</step>

<hr>

<step name="reteach">If the teacher swipes the second slider right, then the 

**'class code' dropdown menu** will activate, and the teacher can select which class he is interested in retrieving summed scores for each student in that class.

![reteach](img/4b_slide_reteach.png)

For example, if the teacher selects the 'reteach' option, and chooses class BCP-180, this is what the GUI should look like:

![BCP-180](img/6_select_class_bcp-180.png)

</step>
